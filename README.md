# Basketball Game

A small browser basketball shooting game.

## Play

Open `index.html` in a browser — no build step or dependencies.

- **Drag back from the ball and release** to shoot (like a slingshot).
- Score as many baskets as you can in 60 seconds.
- Swishes (no rim contact) are worth 3, other makes are worth 2.
- The ball moves to a new spot after each make.
